# Devangi — portfolio

Static one-page portfolio. Plain HTML/CSS/JS, no build step.

- `index.html` — page content
- `assets/style.css`, `assets/main.js` — styles and interactions
- `assets/img/` — images taken from the PDF portfolio
- `Devangi-Portfolio.pdf` — downloadable PDF

Preview locally: `python -m http.server` in this folder.
